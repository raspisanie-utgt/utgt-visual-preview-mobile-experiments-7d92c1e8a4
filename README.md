# Тестовый сайт расписания УТЖТ

Отдельная публичная площадка для проверки визуальных изменений до переноса на основной сайт.

**Основной сайт:** https://raspisanie-utgt.github.io/

**Тестовый адрес:** https://raspisanie-utgt.github.io/utgt-visual-preview-mobile-experiments-7d92c1e8a4/

## Как работает

- GitHub Actions собирает копию сайта из изолированной ветки `claude/snow-mobile-redesign-v2` основного репозитория.
- В тестовой сборке снег по умолчанию включён (ручной режим, 65%). Теперь снежинки физически сталкиваются с карточками и постепенно наращивают сугробы на каждой из них. На основном сайте снег отключён.
- При изменении тестовой ветки нажмите Actions → «Тестовая сборка и публикация УТЖТ» → Run workflow. Публикация происходит ТОЛЬКО в этом репозитории.
- Для первого запуска в Settings → Pages выберите Source: **GitHub Actions**, если публикация ещё не включена.
- Тестовый адрес общедоступен любому, у кого есть ссылка; длинное имя — не защита паролем.

Не добавлять пароли, токены и персональные данные. Не объединять тестовые изменения в основной сайт без проверки и одобрения.
